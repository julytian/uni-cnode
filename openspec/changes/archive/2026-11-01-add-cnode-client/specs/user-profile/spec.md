# Spec Delta: user-profile

## Purpose

提供用户资料浏览能力：我的页（当前登录用户的个人信息与收藏/发布入口）、他人用户主页（通过 loginname 查看任意用户资料、最近主题与回复）。我的页同时承担登录/登出入口职责。

## ADDED Requirements

### Requirement: 我的页展示
系统 SHALL 提供我的页：已登录时 MUST 展示头像、昵称、积分（score）、注册时间，并提供"我的收藏""我的主题""我的消息"入口与退出登录入口；未登录时 MUST 展示登录引导入口。

#### Scenario: 已登录查看我的页
- **WHEN** 已登录用户进入我的页
- **THEN** 页面展示其头像、昵称、积分、注册时间及各功能入口

#### Scenario: 未登录查看我的页
- **WHEN** 未登录用户进入我的页
- **THEN** 页面展示默认头像与"点击登录"引导，点击进入登录页

### Requirement: 我的收藏列表
系统 SHALL 提供我的收藏页，通过 `GET /topic_collect/:loginname` 展示当前用户收藏的全部主题（标题、分类、回复数），点击 MUST 跳转主题详情；空列表 MUST 展示空状态提示。

#### Scenario: 查看收藏列表
- **WHEN** 已登录用户在我的页点击"我的收藏"
- **THEN** 页面展示该用户收藏的主题列表

#### Scenario: 收藏为空
- **WHEN** 用户没有任何收藏
- **THEN** 页面展示空状态提示（如"暂无收藏"）

### Requirement: 他人用户主页
系统 SHALL 支持在任意位置点击用户昵称/头像进入该用户主页，页面通过 `GET /user/:loginname` 展示头像、昵称、积分、注册时间、 GitHub 关联信息，并分"最近创建的话题""最近回复的话题"两个区块展示（数据来自接口返回的 recent_topics / recent_replies），点击条目 MUST 跳转主题详情。

#### Scenario: 查看他人主页
- **WHEN** 用户点击某评论作者的昵称或头像
- **THEN** 页面展示该用户的资料与最近主题、最近回复列表

#### Scenario: 主页条目跳转
- **WHEN** 用户点击主页中"最近创建的话题"下的某个主题
- **THEN** 系统跳转到该主题详情页

### Requirement: 我的主题与回复入口
我的页的"我的主题"与"我的回复"入口 SHALL 复用用户主页能力，以当前登录用户的 loginname 打开对应页面，分别定位到"最近创建的话题"与"最近回复的话题"区块。

#### Scenario: 查看自己发布的主题
- **WHEN** 已登录用户在我的页点击"我的主题"
- **THEN** 系统以当前用户 loginname 打开用户主页并展示其最近创建的话题
